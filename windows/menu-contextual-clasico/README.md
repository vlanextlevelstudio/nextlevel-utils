# Menú contextual clásico de Windows 11

Pequeña utilidad para activar o restaurar el menú contextual clásico de Windows en Windows 11.

## Funciones

- Activar el menú contextual clásico estilo Windows 10.
- Restaurar el menú contextual moderno de Windows 11.
- Reiniciar automáticamente el Explorador de Windows para aplicar los cambios.
- No requiere reiniciar el PC.

## Uso

Ejecuta:

`Menu_contextual_clasico_Windows11.bat`

y selecciona la opción deseada.
