# Next Level Utils

Colección de pequeñas utilidades, scripts y herramientas prácticas creadas por **Next Level Studio**.

El objetivo es resolver necesidades concretas de forma sencilla, principalmente en Windows, evitando programas complejos cuando un pequeño script puede solucionar el problema.

## Utilidades disponibles

### Windows

#### Menú contextual clásico de Windows 11

Permite alternar fácilmente entre:

- Menú contextual clásico estilo Windows 10.
- Menú contextual moderno de Windows 11.
- Reinicio automático del Explorador de Windows para aplicar los cambios.

📁 [Ver utilidad](windows/menu-contextual-clasico/)

## Filosofía del proyecto

- Utilidades pequeñas y fáciles de usar.
- Soluciones simples para problemas concretos.
- Código accesible y modificable.
- Sin instalaciones innecesarias siempre que sea posible.
